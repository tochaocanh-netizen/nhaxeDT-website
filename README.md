# Nhà Xe Dũng Thu - Website

Website giới thiệu nhà xe, xây dựng bằng Node.js + Express + EJS, tông màu chủ đạo màu cam.

## Cài đặt

```bash
npm install
```

## Chạy

```bash
npm start
```

Mở trình duyệt tại http://localhost:3000

## Cấu trúc

- `server.js` - Express server và routing
- `views/` - Các trang EJS (trang chủ, giới thiệu, lịch trình, liên hệ)
- `public/css/style.css` - Giao diện, tông màu cam
